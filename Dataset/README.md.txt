# Dataset Information


Please note that **the dataset is not included in this repository**.  
The dataset we received from **Intuilize** is quite large, so we have stored it separately on **OneDrive**.

### To set things up:

1. **Access the OneDrive link** here https://mnscu-my.sharepoint.com/:f:/r/personal/wu5067bl_go_minnstate_edu/Documents/Price%20Pirates/Dataset?csf=1&web=1&e=NfPEkj.
2. **Download** the contents of the **`dataset/`** folder from OneDrive.
3. **Copy and paste** the downloaded contents into the **`dataset/`** folder in this repository on your local machine.

After doing this, you will be able to run all the model scripts successfully, as they expect the dataset to be located in the `dataset/` folder relative to the code.
