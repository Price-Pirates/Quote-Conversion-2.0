# Feature Selection 

## Overview

In this folder, you will find scripts for automatic feature selection methods, including **Backward Elimination**, **Correlation Coefficient**, and **Variance Threshold**. 

- The **Backward Elimination** and **Correlation Coefficient** scripts are provided for reference but were **not** used in the final model pipeline.
- The **Variance Threshold** method was actually used during feature selection.
- These feature selection scripts are also available in the `models` folder, where you can run them directly.
- **Important:** Before running any script, make sure the file paths to the datasets are correctly set. Update the paths if necessary.

## Scripts

### 1. Backward Elimination
- A script that applies backward elimination to remove less significant features.
- **Note:** Provided for reference only; not used in the final model.



### 2. Correlation Coefficient
- A script that selects features based on the correlation between them.
- **Note:** Provided for reference only; not used in the final model.


### 3. Variance Threshold
- Feature selection based on removing low-variance features.
- **Note:** **This method was used** in the final model preparation.
- Available in both this folder and the `models` folder for execution.


## Summary

- The **Backward Elimination** and **Correlation Coefficient** scripts are for review and experimentation.
- The **Variance Threshold** method was actively used in feature selection.
- Scripts are runnable from both this folder and the `models` folder.
- Always verify and update the dataset paths before executing any scripts.
