# Gradient Boosting Model Folder

## Overview

In this folder, you will find scripts related to the Gradient Boosting model.

- **Note:** The Gradient Boosting model was **not used** in the final project.
- After evaluation, this model produced the **lowest accuracy** compared to the other models.
- As a result, we decided to **drop the Gradient Boosting model** and proceed with the **Decision Tree** and **Random Forest** models instead.



  
**Important:** Before running any scripts, make sure the dataset paths are correctly set. Update the paths if necessary to ensure smooth execution.
